Every method passes through the same gates. Grey = excluded (hover or read the badge for the reason). Coloured = eligible, sized by suitability rank.

4Ranking

Suitability = weighted rubric: data sufficiency 30% · assumption match 30% · parsimony 15% · interpretability gate (pass/fail) · expected runtime 10% · robustness 15%. After running the tournament, blind-test R², AICc, and parameter stability overwrite these estimates.
